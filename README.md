# Network-Inventory-Cleaning-and-Validation

## Description

The purpose of this containerized-DAG-oriented pipeline is to cleanse and validate the observations stored in the inventory_raw.csv provided; detect its anomalies and solve its ambiguous cases –via an LLM-powered FastAPI server– and export the results as inventory_clean.csv.
